# NIZAR DIGITAL — منصة بيع المنتجات الرقمية والبرمجيات

دليل التشغيل والتهيئة الشامل لمنصة **NIZAR DIGITAL** — متجر إلكتروني متكامل للبرمجيات والأنظمة الجاهزة مع الدفع المصرفي بالدينار الليبي (LYD)، نظام تسليم الملفات المشفر، ولوحة التحكم الإدارية.

---

## 🚀 1. نبذة عن المشروع
تم بناء المنصة بأعلى المعايير الهندسية والأمنية:
- **الواجهة:** React 19 + TypeScript + Tailwind CSS (RTL عربي بالكامل).
- **الخادم الخلفي:** Node.js + Express (مع بوابات فك التشفير والتسليم الآمن وإعادة احتساب الأسعار).
- **قاعدة البيانات والتخزين:** PostgreSQL + Supabase (أو محرك التخزين المحلي المدمج المرفق للتشغيل الفوري).
- **العملة المعتمدة:** الدينار الليبي (**LYD**) حصراً.

---

## 🛠️ 2. كيف أنشئ مشروع Supabase؟
1. افتح موقع [Supabase.com](https://supabase.com) وسجل دخولك.
2. اضغط على **"New Project"**.
3. اختر اسماً للمشروع (مثلاً: `nizar-digital`)، وحدد كلمة سر قوية لقاعدة البيانات.
4. اختر أقرب منطقة خوادم لمنطقتك (مثلاً: `Frankfurt (eu-central-1)`).
5. بعد اكتمال الإنشاء، توجه إلى **Project Settings -> API** وانسخ:
   - `Project URL`
   - `anon / public key`
   - `service_role key` (سري للغاية يُستخدم فقط من طرف الخادم).

---

## 🗄️ 3. أين أضع ملف SQL؟
1. داخل لوحة تحكم مشروع Supabase، افتح قسم **SQL Editor** من القائمة الجانبية.
2. افتح ملف `supabase/schema.sql` الموجود في هذا المستودع.
3. انسخ محتواه بالكامل والصقه في الـ **SQL Editor**.
4. اضغط على زر **"Run"** لتنفيذ السكربت.
5. سيقوم السكربت تلقائياً بإنشاء:
   - كافة الجداول (16+ جدول تشمل `profiles`, `products`, `product_options`, `orders`, `payment_submissions`, `download_entitlements`, `service_tasks`, `audit_logs`...).
   - دوال التشفير والصلاحيات (RBAC Functions).
   - سياسات الأمان والحماية الصارمة (**Row Level Security - RLS**).

---

## 📦 4. كيف أنشئ Storage Buckets؟
في حال رغبت بإنشاء الحاويات يدوياً من واجهة Supabase:
1. اذهب إلى قسم **Storage** -> **Create new bucket**.
2. أنشئ الحاويات الثلاث التالية:
   - `project_files`: اجعل خيار **Public bucket** = **OFF** (حاوية خاصة للملفات البرمجية).
   - `payment_receipts`: اجعل خيار **Public bucket** = **OFF** (حاوية خاصة لإيصالات التحويل).
   - `system_assets`: اجعل خيار **Public bucket** = **ON** (لصور المنتجات والشعارات).

---

## 🔑 5. كيف أضبط مفاتيح الاتصال (.env)؟
قم بنسخ ملف `.env.example` إلى ملف باسم `.env`:
```bash
cp .env.example .env
```
وقم بتعبئة المفاتيح:
```env
VITE_SUPABASE_URL="https://xxxxxxxx.supabase.co"
VITE_SUPABASE_ANON_KEY="eyJhbGciOiJIUzI1NiIsIn..."
SUPABASE_SERVICE_ROLE_KEY="eyJhbGciOiJIUzI1NiIsIn..."
PORT=3000
```
> **ملاحظة أمنية:** لا تضع مفتاح `SUPABASE_SERVICE_ROLE_KEY` في أي كود أمامي (Frontend)؛ حيث يتم استخدامه حصراً من جهة خادم Express في `server.ts`.

---

## 👑 6. كيف أنشئ حساب المالك الأول (Owner)؟
1. في قسم **Authentication -> Users** في Supabase، اضغط **Add User** وأدخل بريدك وكلمة المرور.
2. بعد إنشاء المستخدم، انسخ الـ `User UID`.
3. افتح **SQL Editor** ونفّذ الاستعلام التالي لترقية حسابك لمالك رئيسي:
```sql
INSERT INTO public.profiles (id, full_name, email, role, status)
VALUES ('ضع_معرف_المستخدم_هنا', 'نزار الهواري', 'owner@nizardigital.ly', 'owner', 'active')
ON CONFLICT (id) DO UPDATE SET role = 'owner';
```
> وفي النسخة التشغيلية المباشرة في AI Studio، يتوفر شريط التبديل السريع لأدوار الـ RBAC في أعلى الصفحة للاختبار والتجربة الفورية.

## 💻 7. تشغيل المشروع محلياً
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير المشترك (Express + Vite)
npm run dev

# بناء المشروع للنشر النهائي
npm run build
```
افتح المتصفح على: `http://localhost:3000`

---

## 🌐 8. النشر على Vercel أو استضافة سحابية
1. ارفع المشروع على مستودع GitHub.
2. ادخل إلى [Vercel.com](https://vercel.com) واختر **"Import Project"**.
3. أضف متغيرات البيئة (`VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` و `SUPABASE_SERVICE_ROLE_KEY`).
4. اختر إعدادات البناء:
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. اضغط **Deploy**.

## 🛒 9. دورة الاستخدام العملية (سيناريوهات الاختبار):
### أ. رفع وإضافة أول منتج:
- ادخل إلى **لوحة الإدارة** -> قسم **المنتجات** -> **إضافة منتج جديد**.
- أدخل الاسم والسعر بالدينار الليبي والتصنيف.
- يقوم النظام تلقائياً بإنشاء باقات التسعير المرنة وحزم الملفات.

### ب. اختبار التسعير المرن:
- افتح صفحة المنتج، واختبر النموذج المعتمد:
  `1200 د.ل (الملفات) + 700 د.ل (التركيب) + 500 د.ل (التخصيص) + 300 د.ل (الدعم) = 2700 دينار ليبي`.
- لاحظ الحساب الفوري وتحقق القواعد (لا يمكن اختيار التركيب دون ملفات المشروع).

### ج. إتمام الطلب والتحويل المصرفي:
- أكمل الطلب واختر الحساب المصرفي (مصرف الأمان أو مصرف الجمهورية).
- يظهر رقم الطلب والمبلغ المطلوب، ثم نموذج رفع إثبات الحوالة المصرفية.

### د. مراجعة وتأكيد أول دفعة:
- افتح لوحة الإدارة -> **مراجعة المدفوعات**.
- كبّر صورة الإيصال وافحص رقم المرجع واسم المحول والمبلغ.
- اضغط **تأكيد وصول المبلغ واعتماد الطلب (Paid)**.

### هـ. اختبار التحميل الآمن:
- ادخل إلى حساب العميل -> **مركز التحميل الآمن**.
- ستجد الملفات متاحة مع عداد محاولات التنزيل (3 محاولات افتراضية).
- اضغط **بدء التنزيل الآمن** لتوليد رمز أمان فوري وتنزيل الحزمة دون كشف أي مسار تخزين سري.
