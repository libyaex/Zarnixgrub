# قائمة الجاهزية للإنتاج

## ما تم تنفيذه والتحقق منه آلياً (npm test — 48 اختباراً)
- توافق الواجهة والخادم: كل مسار `/api` تستخدمه الواجهة موجود على الخادم بالطريقة الصحيحة (`tests/contract.test.ts`).
- حسابات الطلب والكوبونات من الخادم فقط، والخيارات الإلزامية، ومنع إعادة استخدام الكوبون.
- إثبات الدفع: ملكية الإيصال، وجوده فعلاً في التخزين، منع تكرار المرجع، مطابقة المبلغ، اعتماد ذري لا يكرر التراخيص، وتدقيق كل قرار.
- لا يمكن تعيين `paid` إلا عبر مراجعة المدفوعات، والاسترداد يسحب التنزيلات.
- الصلاحيات: لا تغيير ذاتي للدور، المدير لا يمس المالك ولا يمنح `admin`، الأدوار المخصصة لا تتصعّد.
- رفع الملفات: روابط موقّعة، حدود النوع والحجم، أرشيفات المشاريع لمن يملك `manage_products` فقط.
- حماية معالجات `async` (أي استثناء يعود JSON 500 بدل تعليق الطلب)، وحد معدل لا يثق بترويسة IP المزورة.

## ما لم يُتحقق منه في بيئة التطوير هنا (يلزمك تشغيله)
هذه البيئة بلا شبكة، فلم تُثبَّت الحزم ولم يُشغَّل المتصفح. لذلك:
- [ ] `bun install && npm run verify` (الاختبارات تعمل، لكن `tsc` و`vite build` الكاملين لم يُجرَّيا).
- [ ] تجربة يدوية للدورة الكاملة (الخطوة 4 في `DEPLOYMENT-STEPS.md`) على بيئة تجريبية.
- [ ] الاختبارات تحاكي قاعدة البيانات في الذاكرة؛ لم تُشغَّل على Supabase حقيقي (سياسات RLS، القيود، الفهارس).
- [ ] واجهة المستخدم لم تُفحص بصرياً.

## حدود معروفة (قرارات مؤجلة)
- **حد المعدل** داخل الذاكرة لكل نسخة serverless؛ لحماية صارمة استخدم Vercel Firewall أو Upstash.
- **القوائم الإدارية** تعرض آخر 500 سجل (طلبات/تراخيص/سجلات)؛ أضف ترقيم صفحات عند تجاوز ذلك.
- **لا إشعارات بريدية** (تأكيد الطلب/الاعتماد). أضف Resend/Postmark عند الحاجة.
- **مهام الخدمة** لا تُنشأ تلقائياً من خيارات الطلب؛ تُضاف يدوياً من اللوحة.
- **الإحصائيات** تُحسب في الخادم بالمرور على الطلبات (مناسبة لآلاف الطلبات، لا لملايين؛ انتقل إلى view/RPC عندها).
- **حزم غير مستخدمة** في `package.json` (`@google/genai`، `motion`) لم تُحذف حتى لا ينكسر `bun.lock`؛ احذفها بـ `bun remove` ثم أعد توليد القفل.
- **CSP**: لم تُضف سياسة Content-Security-Policy؛ جرّبها تدريجياً بوضع report-only.
- **الصفحات القانونية** (الشروط/الخصوصية/الاسترجاع) والنسخ الاحتياطي: خارج نطاق الكود.
